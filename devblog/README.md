# Devblog media

Permanent image and animation hosting for Forge of the Elements posts.

Place final media in a folder for each release or post, such as `beta-1.4/`. The public image URL is:

`https://jhffmn82.github.io/forge/devblog/<release-or-post>/<filename>`

Use those absolute URLs in blog HTML, including itch.io posts. Existing filenames and URLs must stay available after publication; use new filenames for replacements. Keep raw captures, diagnostics and unpublished prose out of this archive.

Game deployments must preserve this entire `devblog/` directory. These files are separate from the game runtime and its offline precache.

For blog embeds, omit fixed `width` and `height` attributes from image tags. An editor may strip `height:auto` while constraining image width, which distorts an image with a fixed height. The `-720w.jpg` screenshots are proportional, post-sized copies; original URLs remain available.
