# Forge of the Elements - Beta 1.4

[Play in your browser](https://jhffmn82.github.io/forge/).

Explore elemental dungeons, shape your build at the Forge, and face each biome's boss. Beta 1.4 adds new enemies, coordinated support behavior, persistent ground hazards and counterplay, better pursuit around corners, and a rebuilt interface for landscape phones, tablets and PCs.

Keyboard, mouse and touch controls are supported. Phones and tablets use landscape; a rotate-device prompt appears when the browser cannot lock orientation. Use your browser's installation controls for an installed app.

[Beta 1.4 patch notes](PATCH-NOTES.md). The in-game Version button also lists changes and checks for updates.
